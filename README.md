# mp3-key-changer

ブラウザだけで MP3 ファイルを読み込み、半音単位でキーを変更しながら再生できるシンプルなプレイヤーです。

## 主な機能

- 複数 MP3 ファイルのプレイリスト登録
- トラッククリックによる曲選択
- 再生 / 一時停止 / 停止 / 次の曲への移動
- シャッフル再生
- -12 〜 +12 半音のキー変更
- 再生位置のシーク
- 再生時間表示
- iOS / モバイルブラウザ向けの簡易的な背景再生維持処理

## 使い方

1. `index.html` をブラウザで開きます。
2. ファイル選択から MP3 ファイルを追加します。
3. プレイリストの曲をクリックして再生します。
4. キー変更スライダー、再生位置スライダー、再生制御ボタンを使います。

## 注意点

- 音声処理には Tone.js を CDN から読み込んでいます。インターネット接続がない環境では動作しません。
- MP3 をブラウザ上で全体読み込み・デコードするため、長時間音源や大容量ファイルではメモリ使用量が増えます。
- 背景再生の挙動はブラウザや OS の制限に影響されます。
